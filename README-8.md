# みっちー財政カルテ 🐧

**みっちーと学ぶ財政カルテ｜全国の市区町村・都道府県の財政健全度をチェック**

🔗 https://ray-ray870.github.io/mitchie-fiscal/

自分の街、そして日本全国の自治体の財政が、今どんな状態にあるのかを、紫色のペンギン「みっちー」と一緒に楽しく・分かりやすくチェックできる非公式アプリです。

---

## このアプリについて

日本の多くの自治体は今、決して楽ではない財政状況にあります。「絶好調」な自治体がある一方で、「ちょっとしんどい」「ぐったり」「ひんし状態」という水準の自治体も少なくありません。

このアプリでは、あえて自治体の規模や産業構造で調整せず、全国の自治体を同じものさしで単純比較しています。これは、今の日本の自治体財政の厳しさを、ありのままに知ってもらいたいという想いによるものです。

同時に、人口減少に合わせて運営をコンパクトにしたり、独自の取り組みで税収を増やしたりして、規模の大きな自治体に見劣りしないスコアを出している小さな自治体を見つけてもらうことも、このアプリの目的の一つです。

自分の街のことを知る、そして日本の地方自治に目を向ける。その最初の一歩にこのアプリがなれば幸いです。

## 主な機能

- **財政タブ**：財政力指数・実質公債費比率・経常収支比率・将来負担比率・財政調整基金など、決算統計ベースの主要な財政指標をチェック
- **公会計タブ**：財政タブの「毎年のお金の出入り」とは異なる角度で、資産・負債といったストック情報（貸借対照表のような視点）を含む、統一的な基準による財務書類のデータをチェック
- **財政×公会計のクロスチェック**：財政タブ（フロー＝毎年のお金の出入り）と公会計タブ（ストック＝これまでの蓄積）、両方の数値を組み合わせて見られる機能。総務省の分析資料にあるクロスチェックの考え方を参考にしています
- **ふるさと納税**：受入額と住民税控除額を比較表示
- **Myみっちー**：自分の住む街・応援したい街を登録し、全国・都道府県内での順位をチェック
- **全国のみっちー**：全国・地方ブロックごとの分布や、都道府県ランキングをチェック
- **総合健全度スコア**：0〜100点で財政状態をひと目で把握できる、このアプリ独自のスコアです。総務省が公式に定めた指標ではありません。市区町村と都道府県で基準が異なります。

  **市区町村**
  - 財政力指数：25点（1.2以上で満点、0に近いほど点数が下がります／※この指標のみ%ではなく数値です）
  - 実質公債費比率：20点（0%に近いほど高得点、25%以上で0点になります）
  - 経常収支比率：20点（85%以下なら満点、100%以上で0点になります）
  - 将来負担比率：20点（0%以下なら満点、200%以上で0点になります）
  - 財政調整基金：15点（標準財政規模の20%以上あれば満点）

  **都道府県**（大規模な資産を抱え、将来負担比率や経常収支比率の水準が構造的に高くなるため、基準値を緩めに設定）
  - 財政力指数：25点（0.90以上で満点、0.20以下で0点／※この指標のみ%ではなく数値です）
  - 実質公債費比率：20点（6%以下で満点、20%以上で0点）
  - 経常収支比率：20点（86%以下で満点、101%以上で0点）
  - 将来負担比率：20点（80%以下で満点、340%以上で0点）
  - 基金比率：15点（標準財政規模の10%以上あれば満点）

## データの出典

総務省が公表している以下の一次データを使用しています。

- 地方財政状況調査（決算統計）
- 地方公共団体の主要財政指標一覧
- 統一的な基準による財務書類に関する情報
- ふるさと納税に関する現況調査

## 技術構成

- ビルドツールなし、ES5のみで動作する素のHTML / CSS / JavaScript
- JavaScriptは `data.js`・`score.js`・`ranking.js`・`search.js`・`comparison.js`・`share.js`・`my-mitchie.js`・`kokaikei.js`・`ui.js` の9ファイルに分割
- GitHub Pagesでホスティング
- GitHub Actionsで年次データ更新・デプロイ前の自動チェックを半自動化
