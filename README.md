# みっちー財政カルテ 🐧

**みっちーと学ぶ財政カルテ｜全国の市区町村・都道府県の財政健全度をチェック**

🔗 https://ray-ray870.github.io/mitchie-fiscal/

自分の街、そして日本全国の自治体の財政が、今どんな状態にあるのかを、紫色のペンギン「みっちー」と一緒に楽しく・分かりやすくチェックできる非公式アプリです。

---

## このアプリについて

日本の多くの自治体は今、決して楽ではない財政状況にあります。「絶好調」な自治体がある一方で、「ちょっとしんどい」「ぐったり」「ひんし」という水準の自治体も少なくありません。

このアプリでは、あえて自治体の規模や産業構造で調整せず、全国の自治体を同じものさしで単純比較しています。これは、今の日本の自治体財政の厳しさを、ありのままに知ってもらいたいという想いによるものです。

同時に、人口減少に合わせて運営をコンパクトにしたり、独自の取り組みで税収を増やしたりして、大きな自治体と並ぶスコアを叩き出している小さな自治体を見つけてもらうことも、このアプリの目的の一つです。

自分の街のことを知る、そして日本の地方自治に目を向ける。その最初の一歩にこのアプリがなれば幸いです。

## 主な機能

- **財政タブ**：財政力指数・実質公債費比率・経常収支比率・将来負担比率・財政調整基金など、決算統計ベースの主要な財政指標をチェック
- **公会計タブ**：財政とは違う切り口で、資産・負債といったストック情報（貸借対照表的な視点）を含む、統一的な基準による財務書類のデータをチェック
- **財政×公会計のクロスチェック**：フロー（財政）とストック（公会計）、両方の視点を組み合わせた分析（総務省公式の分析手法も一部採用）
- **ふるさと納税**：受入額と住民税控除額を比較表示
- **Myみっちー**：自分の住む街・応援したい街を登録し、全国・都道府県内での順位をチェック
- **全国のみっちー**：全国・地方ブロックごとの分布や、都道府県ランキングをチェック
- **総合健全度スコア**：複数の指標を組み合わせた0〜100点のスコアで、財政状態をひと目で把握

## データの出典

総務省が公表している以下の一次データを使用しています。

- 地方財政状況調査（決算統計）
- 地方公共団体の主要財政指標一覧
- 統一的な基準による財務書類に関する情報
- ふるさと納税に関する現況調査

## 技術構成

フレームワークを使わない、素のHTML / CSS / JavaScriptで構築しています。GitHub Pagesでホスティングしており、データ更新もGitHub Actionsで半自動化しています。
