# 年次データ更新の手順

3月末は、総務省の新しいExcelのURLを `scripts/config.json` に書き、ワークフローを1つ実行するだけです。
画面の「令和◯年度」や全国の中央値、起債許可団体などの一覧は、データから自動で決まるので書き換え不要です（2026-09-30〜）。

## 年間スケジュール

| 時期 | やること | 使うワークフロー |
|---|---|---|
| **3月末** | 財政データの更新（新しい年度） | 年次データ更新（プレビュー） |
| **8月初め** | 人口の更新（1月1日現在の人口。7〜8月に公表） | 年次データ更新（プレビュー） |
| **8月初め** | ふるさと納税の更新（7月末〜8月初めに公表） | ふるさと納税データ更新 |
| **11月末** | 健全化判断比率の確報PDFの確認（確認のみ） | なし |
| 必要なとき | 公式データとの照合・リハーサル（確認のみ） | 公式データとの照合／年次更新のリハーサル |

3月25日・8月5日・11月25日に、Claudeの「スケジュール済みタスク」が自動で動いて、新しいURLを探して知らせてくれます（2026-09-30に登録）。

### 人口だけの更新（8月）

`scripts/config.json` の `population` の `muni`（【総計】令和◯年住民基本台帳人口・世帯数（市区町村別）のURL）と、
`population_year_label`（例：`令和9年`）だけを書き換えて、「年次データ更新（プレビュー）」を実行する。
財政の `fiscal_year_label` はそのままでよい（財政は同じ年のまま実行しても壊れない）。
プレビューで確認してから「プレビューのデータを本番に反映」。

## 【3月末】メイン更新

### ① 総務省サイトで新年度のExcelを探す（Claudeに手伝ってもらう）

Claudeに「今年のデータに更新して」と声をかければ、URLを一緒に探してくれます。

| config.json の欄 | 中身 | 年 |
|---|---|---|
| `fiscal_indicators` | 全市町村・全都道府県の主要財政指標一覧 | 新しい年度 |
| `reserve_fund` | 基金残高等一覧（財政調整基金） | 新しい年度 |
| `budget` | 決算状況調（市・町村・都道府県。歳出歳入・実質赤字比率） | 新しい年度 |
| `purpose_expenditure` | 目的別歳出内訳（市・町村・都道府県） | 新しい年度 |
| `age_population` | 住民基本台帳 年齢階級別人口 | 新しい年度の**次の年** |
| `sfs` の `base_muni`・`pref_card` | 決算カード（標準財政規模） | 新しい年度 |
| `population` | 住民基本台帳 人口・世帯数 | 人口は毎年7〜8月公表なので、**3月はそのままでよい** |

公会計は、総務省のページを自動で見に行き、新しい年度が公表されていれば取り込みます（URLの書き換えは不要）。

### ② `scripts/config.json` を書き換える

GitHubアプリで `scripts/config.json` を開き、①のURLと、一番上の `fiscal_year_label`（例：`令和7年度`）を書き換えてコミット。
人口のURLを新しい年にしたときだけ `population_year_label` も書き換える。

> 年やURLの書き換え忘れ（去年のExcelのまま等）は、ワークフローが赤い×で止まって知らせます。データは壊れません。

### ③ 「年次データ更新（プレビュー）」を実行

Actions の **年次データ更新（プレビュー）** で「Run workflow」。
財政・人口 → 標準財政規模 → 公会計 → 自治体の顔ぶれのチェック → **公式データとの照合（全項目・全年度）** の順に自動で行い、
すべて通ったときだけ `preview/` に保存して、プレビューを公開します（本番には触りません）。

- 赤い×で止まったとき：実行画面の Summary（または赤い×の行）を Claude に見せる。何も保存されていないので、直してもう一度実行すればよい
- Summary に「自治体の数が◯◯になりました」と出たとき（合併など）：`preview/index.html` の「全国1,788自治体」（2か所）と「約1,788自治体対応」を書き換える

### ④ プレビューで確認

https://ray-ray870.github.io/mitchie-fiscal/preview/ で、いくつかの自治体を開き、「令和◯年度」が新しい年度になっているか、グラフの右端が新しい年度か、を確認。

### ⑤ 本番に反映

1. 「プレビューのデータを本番に反映」を実行
2. 「プレビューを本番に反映」を実行（画面のプログラムにも変更があるときのため。変更が無ければ何もしない）

### 事前の確認（リハーサル）

Actions の **年次更新のリハーサル（確認のみ）** は、③と同じスクリプトを今の公式データで試し、今のアプリのデータと同じ結果になるかを確かめます。
データは書き換えません。スクリプトを直したときや、3月の前に実行して、すべて緑のチェックなら安心です。

### 照合だけしたいとき

Actions の **公式データとの照合（確認のみ）** で、本番かプレビューを選んで実行（データは書き換えません）。

## 【8月】ふるさと納税の更新

ふるさと納税の数字（受入額・住民税控除額）は、3月末の年次更新には**含まれません**。総務省が毎年**7月末〜8月初め**に「ふるさと納税に関する現況調査結果」を公表するので、そのあとに別で更新する。

### ① 総務省サイトで新年度のExcelを2つ探す（Claudeに手伝ってもらう）

Claudeに「ふるさと納税を今年のデータに更新して」と声をかければ、URLを一緒に探してくれます。必要なのは次の2つだけ：

1. **各自治体のふるさと納税受入額及び受入件数（平成20年度～令和X年度）** … 全年度の推移が1ファイルに入っている
2. **各自治体の令和Y年度課税における住民税控除額等** … 最新の1年分（Y = X + 1）

※ 過去の控除額ファイルは不要。今のデータの過去7年分を1年ずらして使う。

### ② ワークフローを実行

https://github.com/ray-ray870/mitchie-fiscal/actions/workflows/furusato-update.yml で「Run workflow」を押し、2つのURLを貼り付けて実行。

- `preview/data-*.json` と `preview/js/ui.js`（グラフの年度ラベル）が自動で更新される。本番には触らない
- 自治体名が1件でも合わない、年度が合わない、などのときは止まって何も書き込まない（ログの「NG:」の行を Claude に見せる）

### ③ プレビューで確認

https://ray-ray870.github.io/mitchie-fiscal/preview/ で、いくつかの自治体のふるさと納税の詳細を開き、グラフの年度（右端が新年度になっているか）と数字を確認。同名自治体（伊達市（北海道）・朝日町（山形）など）も見ておく。

### ④ 本番に反映

1. 「プレビューのデータを本番に反映」を実行
2. 「プレビューを本番に反映」を実行（ui.js の年度ラベルを反映するため）

### 注記（指定取消しなど）の追加

返礼品の基準違反などで自治体がふるさと納税の対象から外れたときは、`scripts/furusato_notes.json` に1件足して、もう一度②を実行する（同じURLのままでよい。同じ年度で再実行しても数字は変わらず、注記だけ反映される）。

### データが壊れたときの作り直し

控除額の8年分をすべて総務省のExcelから作り直す場合は、`scripts/build_furusato.py` を `--full` 付きで実行する（Excel 9つが必要なので、Claude に頼んで実行してもらう）。

処理スクリプト：`scripts/build_furusato.py`（注記：`scripts/furusato_notes.json`、自動記録：`scripts/furusato_config.json`）

## 【11月末】確認のみの軽い更新

総務省が毎年11月末頃に公表する「健全化判断比率・資金不足比率の概要（確報）」PDFを確認し、**都道府県が実質赤字比率・連結実質赤字比率で基準超えになっていないか**を照合する。

- 確認先：https://www.soumu.go.jp/main_sosiki/c-zaisei/kouei_kessan.html の「決算の概要（速報）」欄
- 確認する内容：都道府県（47団体）が引き続き「早期健全化基準以上の団体はなし」となっているか
- 該当があった場合のみ、Claudeに伝えて個別対応（ファイルの再取得は基本的に不要）

## 起債許可団体・早期健全化団体・財政再生団体の判定基準

| 指標 | 早期健全化基準 | 財政再生基準 |
|---|---|---|
| 実質赤字比率 | 都道府県3.75% / 市町村11.25〜15% | 都道府県5% / 市町村20% |
| 連結実質赤字比率 | 都道府県8.75% / 市町村16.25〜20% | 都道府県15% / 市町村30% |
| 実質公債費比率 | 25%（共通） | 35%（共通） |
| 将来負担比率 | 都道府県・政令市400% / 市町村350% | 基準なし |
| 起債許可団体 | 実質公債費比率18%以上（共通） | ― |

- 市町村分の実質赤字比率・連結実質赤字比率は「決算状況調（概要）」ファイルに含まれる列（36列目・37列目）から取得（新規ファイル取得は不要）
- 都道府県分の実質赤字比率・連結実質赤字比率は、単体のExcelファイルが総務省から一般公開されていないため、11月末の確報PDFで代替確認する運用としている
- 実質公債費比率・将来負担比率は市町村・都道府県とも既存データからそのまま判定可能

処理スクリプト：`scripts/update_fiscal_data.py`・`scripts/fetch_sfs.py`・`scripts/build_kokaikei.py`（照合：`scripts/audit_official_data.py`、リハーサル：`scripts/rehearse_annual_update.py`）
